# Security Policy

Seenivers is no longer under active development. The latest release is the final maintenance release.

Seenivers.com is no longer operated as a support contact, and there is no general Seenivers support mailbox.

## Supported Versions

Only the latest released version is considered current. Older versions are not maintained.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest version | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

Please report Seenivers security issues to **info@webretter.com**. This address is only for security reports and security disclosures about the Seenivers project. It is not a general support inbox.

In the subject line and in the message, please mention **Seenivers** clearly so the report can be identified.

You can also report vulnerabilities through GitHub:

1. Use the **[Security Advisory](https://github.com/Seenivers/app/security/advisories)** system.
2. Alternatively, use **[Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** if it is enabled for this repository.

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- A proof of concept, if available

Please do not publicly disclose the issue until it has been reviewed.

Because this project is no longer under active development, response times may vary.
